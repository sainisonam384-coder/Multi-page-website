## 📌 About The Project

Welcome to Multi-page Website Deployment! This project includes **Home, About, Services, and Contact** pages, with shared navigation and responsive styling.

### ✨ Key Features
- ⚡ Four linked pages: Home, About, Services, and Contact
- 🧭 Shared navigation menu
- 📱 Responsive layout for desktop and mobile screens
- 🎨 Services displayed using CSS Grid
- 💅 Consistent styling with a shared CSS file
- 📩 Contact form design (front-end only)

## 🎯 Project Objective

To create a multi-page website using HTML and CSS, manage the source code with Git and GitHub, and deploy the static website using Amazon S3.

## 🛠️ Tech Stack & Tools

- **Version Control:** Git
- **Hosting:** GitHub
- **Cloud:** Amazon S3 Static Website Hosting
- **Frontend:** HTML5, CSS3
- **Docs:** Markdown
